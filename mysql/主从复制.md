# 主从复制

## 主数据库
1. 修改配置文件，添加
 - log_bin = mysql-bin          #开启日志
 - binlog_do_db = 数据库名    #日志记录那些数据库
2. 备份数据库
3. 执行`show master status;`，记录File和Position
## 从数据库
1. 还原主数据库
2. 进入mysql命令，执行`change master to master_host ='152.136.45.163',master_port=3306,master_user='root',master_password='Bjht12345678@',master_log_file='mysql-bin.000002',master_log_pos=2284476;`，注意替换内容
3. start slave;
