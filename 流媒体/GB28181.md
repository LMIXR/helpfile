2. 代码 
    - WVP https://github.com/swwheihei/wvp-GB28181
    - ZLMediaKit https://github.com/xia-chu/ZLMediaKit
    - MediaServerUI https://gitee.com/kkkkk5G

## WVP

1. 安装Redis。
2. 安装ffmpeg，`sudo add-apt-repository ppa:jonathonf/ffmpeg-4`, `sudo apt update`, `sudo apt install -y ffmpeg`
3. 代码是springboot程序，修改配置文件application.yml，jar已编译好，直接修改和jar同目录的application.yml文件即可，start.sh里是启动加载参数，不用修改源码。
4. 修改redis配置。
5. 修改sip配置，ip是本机ip地址，port按实际修改，domain和id根据国标修改， password修改。
6. 修改server，port修改，是web的端口。
7. 修改media，ip是ZLMediaKit所在服务器地址，port是rtp_proxy端口地址，如果是在外网使用，请填写外网ip和端口。
8. 修改摄像头配置，如海康-配置-网络-高级配置-平台接入，平台介入方式修改为28181，下面平台1协议版本修改为GB/T28181-2016，SIP服务器ID、SIP服务器域、SIP服务器地址、SIP服务器端口、密码根据上面配置进行修改。
9. 查询设备 server的ip:port/api/devices。
10. ZLMediaKit搭建好后，推流 server的ip:port/api/play/{deviceId}/{channelId}，deviceId和channelId是上面接口获取的，返回结果转出16进制后边会用到。
11. 接口地址 https://github.com/swwheihei/wvp-GB28181/wiki/API-%E6%8E%A5%E5%8F%A3
12. 把wvp放到/opt/mediaserver中（jar包不包括在内）wvp.server注册到systemctl。

## ZLMediaKit

1. 获取代码
    - git clone --depth 1 https://gitee.com/xiahcu/ZLMediaKit
    - cd ZLMediaKit
    - git submodule update --init
2. 构建程序，编译后的程序在release/linux/Debug里。
    - mkdir build
    - cd build
    - cmake ..
    - make -j4
3. 将conf/config.ini拷贝到程序所在目录，根据实际情况修改端口号，特别是ffmpeg的位置。
4. 运行程序，./MediaServer
5. 接口地址 https://github.com/xia-chu/ZLMediaKit/wiki/MediaServer%E6%94%AF%E6%8C%81%E7%9A%84HTTP-API
6. 把程序放到/opt/mediaserver/zlmedia中，配置文件也放入其中。zlmedia.server注册到systemctl。

## MediaServerUI

1. 修改global.js，serverip修改为ZLMediaKit的ip地址和http端口号，secret和ZLMediaKit保持一致

## 推流

1. url规则 https://github.com/xia-chu/ZLMediaKit/wiki/%E6%92%AD%E6%94%BEurl%E8%A7%84%E5%88%99。
2. 调用 http://{ZLMediaKit的ip地址}:{ZLMediaKit的http端口}/index/api/getMediaList?secret={ZLMediaKit的secret}&schema=rtsp， schema根据流的类型进行修改，返回值中关注app,stream。
3. 用vlc打开 rtsp://{ZLMediaKit的ip地址}:554/{上面返回的app名字}/{WVP推流返回值转出16进制}?token={ZLMediaKit的secret}&field=value

## 公网安装

1. 安装jdk，sudo apt-get install openjdk-8-jdk
2. 将WVP打包成jar后，测试运行 jar -jar wvp.jar，用摄像头连接服务器，观察是否链接成功。
3. 安装cmake，sudo apt-get install cmake
4. 安装编译器，sudo apt-get install build-essential
5. 安装ffmpeg，sudo apt-get install ffmpeg

## 服务配置

### WVP

1. 创建启动文件，`sudo vi /opt/mediaserver/wvp/start.sh` 修改权限`sudo chmod a+x /opt/mediaserver/wvp/start.sh`。
2. 创建停止文件，`sudo vi /opt/mediaserver/wvp/stop.sh` 修改权限`sudo chmod a+x /opt/mediaserver/wvp/stop.sh`。
3. 创建服务文件 `sudo vi /etc/systemd/system/wvp.service`, 修改权限`sudo chmod a+x /etc/systemd/system/wvp.service`。
4. 通知有新服务`sudo systemctl daemon-reload`。
5. 启动`sudo systemctl start wvp.service`，停止 `sudo systemctl stop wvp.service`，查看状态`sudo systemctl status wvp.service`，启用`sudo systemctl enable wvp.service`。
6. 创建logrotate文件，`sudo vi /etc/logrotate.d/wvp`，启用`sudo logrotate -f /etc/logrotate.d/wvp`
7. 定时删除日志，`crontab -e`, `0 10 * * * /opt/mediaserver/wvp/auto-del-log.sh`
'
