## WVP

1. 安装Redis。
2.  代码是springboot程序，修改配置文件application.yaml。
3. 修改redis配置。
4. 修改sip配置，ip是本机ip地址，port按实际修改，domain和id根据国标修改， password修改。
5. 修改server，port修改，是web的端口。
6. 修改media，ip是ZLMediaKit所在服务器地址，port是rtp_proxy端口地址。
7. 修改摄像头配置，如海康-配置-网络-高级配置-平台接入，平台介入方式修改为28181，下面平台1协议版本修改为GB/T28181-2016，SIP服务器ID、SIP服务器域、SIP服务器地址、SIP服务器端口、密码根据上面配置进行修改。
8. 查询设备 server的ip:port/api/devices。
9. ZLMediaKit搭建好后，推流 server的ip:port/api/play/{deviceId}/{channelId}，deviceId和channelId是上面接口获取的，返回结果转出16进制后边会用到。

## ZLMediaKit

1. 获取代码
    - git clone --depth 1 https://gitee.com/xiahcu/ZLMediaKit
    - cd ZLMediaKit
    - git submodule update --init
2. 构建程序，编译后的程序在release/linux/Debug里。
    - mkdir build
    - cd build
    - cmake ..
    - make -j4
3. 将conf/config.ini拷贝到程序所在目录，根据实际情况修改端口号
4. 运行程序，./MediaServer


## 推流

1. url规则 https://github.com/xia-chu/ZLMediaKit/wiki/%E6%92%AD%E6%94%BEurl%E8%A7%84%E5%88%99。
2. 调用 http://{ZLMediaKit的ip地址}:{ZLMediaKit的http端口}/index/api/getMediaList?secret={ZLMediaKit的secret}&schema=rtsp， 返回值中关注app,stream。
