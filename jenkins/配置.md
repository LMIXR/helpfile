# 配置

## 全局工具配置

### MacOS

1. Manage Jenkins - Global Tool Configuration。
2. JDK
    - 别名，填入“jdk1.8”
    - 查找jdk路径`/usr/libexec/java_home`，返回java真实路径`/Library/Java/JavaVirtualMachines/jdk1.8.0_171.jdk/Contents/Home`，填入“JAVA_HOME”
3. Git
    - Name，填入“Default”
    - 查找git路径`which git`，返回`/usr/bin/git`，填入“Path to Git executable”
4. Maven
    - 安装 brew install maven
    - Name，填入“maven”
    - 查找maven路径`mvn --version`,返回`/usr/local/Cellar/maven/3.6.1/libexec`，填入“MAVEN_HOME”

## 插件

1. Maven项目，Maven Integration 和 Deploy to container。

## 远程Tomcat

1. 编辑Tomcat中的文件`conf/tomcat-users.xml`，添加`<role rolename="manager-script"/>`，`<role rolename="manager-gui"/>`，`<user username="admin" password="admin" roles="manager-gui,manager-script" />`。
2. 编辑Tomcat中的文件`webapps/manager/META-INF/context.xml`，注释掉`<Valve className="org.apache.catalina.valves.RemoteAddrValve" allow="127\.\d+\.\d+\.\d+|::1|0:0:0:0:0:0:0:1" />`
3. 重启Tomcat。
