# 系统

## 修改时区
1. `sudo timedatectl set-timezone "Asia/Shanghai"`

## 修改时间
1. 修改日期 `sudo date -s 11/28/20`
2. 修改时间 `sudo date -s 11:21:30`
3. 修改日期和时间 `date -s '2017-7-17 7:17'`

## 磁盘清理

1. `du -h --max-depth=1 `
2. `du -h -d 1`

## 查看进程文件

1. `sudo su`
2. `ls -al /proc/进程号`

## 修改文件权限

1. `lsattr ***`
2. 如果显示ia，说明无法删除需要先去掉，`chattr -ai ***`

## htop

1. `sudo snap install htop`

## dpkg

1. 安装 `sudo dpkg -i **`
2. 查看 `dpkg -l |grep **`
3. 卸载 `dpkg -P **`

## 端口转发
1. 把某个tcp端口数据转发到另一个端口
   `sudo iptables -t nat -A PREROUTING -p tcp  -m tcp --dport 2051 -j DNAT --to-destination 192.168.0.152:2001`
