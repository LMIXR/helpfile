# 显卡环境

## 安装系统 18.04

1. 在grub界面，高亮`install ubuntu`，按`e`进入命令行模式，然后在quiet slash -- 后面输入 `acpi_osi=linux nomodeset`，按`F10`。
2. 更新软件库  `sudo apt-get update`。
3. 更新vim，`sudo apt-get remove vim-common`，`sudo apt-get install vim`。
4. 禁用自带显卡驱动 `sudo vim /etc/modprobe.d/blacklist.conf`，在最后插入`blacklist nouveau`和`options nouveau modeset=0`，保存退出。更新系统`sudo update-initramfs -u`。重启系统。
5. 验证nouveau是否已禁用 `lsmod | grep nouveau`。
6. 安装gcc等编译工具 `sudo apt install build-essential`。
7. 停止图形界面 `sudo service lightdm stop`。
8. 下载驱动，添加权限 `sudo chmod a+x NVIDIA-Linux-x86_64-440.82.run`, 安装`sudo ./NVIDIA-Linux-x86_64-440.82.run  -no-x-check -no-nouveau-check -no-opengl-files`。
9. 验证是否安装成功 `nvidia-smi`。


## 安装系统 18.04 图形界面安装后可以进入

1. 更新软件库  `sudo apt-get update`。
2. 安装lightdm `sudo apt-get install lightdm`。
3. 屏蔽开源驱动 nouveau，`sudo vi /etc/modprobe.d/blacklist.conf`，添加 `blacklist nouveau`
4. 删除旧NVIDIA驱动 `sudo apt-get --purge remove nvidia-*` `sudo apt-get --purge remove xserver-xorg-video-nouveau`
5. 重启电脑
6. 按Ctrl + Alt +F1进入命令行模式，`sudo service lightdm stop`。
7. 安装gcc等编译工具 `sudo apt install build-essential`。
8. 下载驱动，添加权限 `sudo chmod a+x NVIDIA-Linux-x86_64-440.82.run`, 安装`sudo ./NVIDIA-Linux-x86_64-440.82.run  -no-x-check -no-nouveau-check -no-opengl-files`。
9. 验证是否安装成功 `nvidia-smi`。

## jetson tx2

### jtop在线安装

1. 无法使用nvidia-smi命令查看GPU使用情况，使用jtop工具，安装`sudo -H pip install jetson-stats`,使用`sudo jtop`

### jtop 离线安装

1. 先安装setuptools,用python安装不用python3
2. 下载jtop源码,`git clone https://github.com/rbonghi/jetson_stats.git`, 编译`sudo python ./setup.py install`

## xavier nx

1. 安装setuptools，下载`https://pypi.python.org/packages/source/s/setuptools/setuptools-0.6c11.tar.gz#md5=7df2a529a074f613b509fb44feefe74e`，解压进入，执行`python setup.py build`，`sudo python setup.py install`,如果提示错误缺少目录`/usr/local/lib/python2.7/dist-packages/`，创建即可。

## 其他
1. 重装显卡版本不一样，回提示卸载当前版本显卡。
2. 查找合适的驱动版本 `ubuntu-drivers devices`。
3. 查看显卡型号`lspci | grep -i vga`，根据最后四位数字，在`http://pci-ids.ucw.cz/mods/PC/10de?action=help?help=pci`。
4. 查看算力 https://developer.nvidia.cn/zh-cn/cuda-gpus
5. 查看显卡型号 `nvidia-smi -L`

## 驱动不一致问题
1. 输入`nvidia-smi`提示`Failed to initialize NVML: Driver/library version mismatch`,是由于显卡内核版本和安装的驱动版本不一致造成的，安装的驱动版本高于显卡内核版本，需要卸载驱动，安装相应版本，`https://www.nvidia.cn/Download/Find.aspx`查找版本。
2. 查看显卡驱动所使用的内核版本, `cat /proc/driver/nvidia/version`。
3. 查看驱动程序，`sudo dpkg --list | grep nvidia-*`
4. 卸载
    - sudo /usr/bin/nvidia-uninstall
    - sudo apt-get --purge remove nvidia-*
    - sudo apt-get purge nvidia*
    - sudo apt-get purge libnvidia*
    - sudo apt-get autoremove

    ## 查看显卡算力

    1. `https://developer.nvidia.com/cuda-gpus#collapseOne`
    2. `https://developer.nvidia.com/cuda/gpus`
5. 错误`CUDA initialization failure with error: 999`, 重新加载nvidia模块`sudo rmmod nvidia_uvm`，
       `sudo modprobe nvidia_uvm`
6. 错误`Failed to initialize NVML: Driver/library version mismatch`, 显卡驱动自动升级导致，重启服务器
