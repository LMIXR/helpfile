# 显卡环境

## 安装系统 18.04

1. 在grub界面，高亮`install ubuntu`，按`e`进入命令行模式，然后在quiet slash -- 后面输入 `acpi_osi=linux nomodeset`，按`F10`。
2. 更新软件库  `sudo apt-get update`。
3. 更新vim，`sudo apt-get remove vim-common`，`sudo apt-get install vim`。
4. 禁用自带显卡驱动 `sudo vim /etc/modprobe.d/blacklist.conf`，在最后插入`blacklist nouveau`和`options nouveau modeset=0`，保存退出。更新系统`sudo update-initramfs -u`。重启系统。
5. 验证nouveau是否已禁用 `lsmod | grep nouveau`。
6. 安装gcc等编译工具 `sudo apt install build-essential`。
7. 停止图形界面 `sudo service lightdm stop`。
8. 下载驱动，添加权限 `sudo chmod a+x NVIDIA-Linux-x86_64-440.82.run`, 安装`sudo ./NVIDIA-Linux-x86_64-440.82.run  -no-x-check -no-nouveau-check -no-opengl-files`。
9. 验证是否安装成功 `nvidia-smi`。


## 安装系统 18.04 图形界面安装后可以进入

1. 更新软件库  `sudo apt-get update`。
2. 安装lightdm `sudo apt-get install lightdm`。
3. 屏蔽开源驱动 nouveau，`sudo gedit /etc/modprobe.d/blacklist.conf`，添加 `blacklist nouveau`
4. 删除旧NVIDIA驱动 `sudo apt-get --purge remove nvidia-*` `sudo apt-get --purge remove xserver-xorg-video-nouveau`
5. 重启电脑
6. 按Ctrl + Alt +F1进入命令行模式，`sudo service lightdm stop`。
7. 安装gcc等编译工具 `sudo apt install build-essential`。
8. 下载驱动，添加权限 `sudo chmod a+x NVIDIA-Linux-x86_64-440.82.run`, 安装`sudo ./NVIDIA-Linux-x86_64-440.82.run  -no-x-check -no-nouveau-check -no-opengl-files`。
9. 验证是否安装成功 `nvidia-smi`。
