# 代理

## privoxy

1. 安装 `sudo apt-get install privoxy`
2. 编辑代理配置文件`sudo gedit /etc/privoxy/config `，找到`forward-socks5t`，去掉#注释，端口改成1080
3. 重启代理服务`sudo service privoxy restart`
4. 使用代理服务，终端输入
    - export http_proxy='http://127.0.0.1:8118' 
    - export https_proxy=$http_proxy
5. 验证 curl ip.gs，如果显示代理服务器地址就对了
