# 树莓派

## 安装系统

1. 下载 https://ubuntu.com/download/raspberry-pi
2. 不用解压，用etcher烧录。

## 配置

1. 默认用户名密码是ubuntu/ubuntu，第一次登录会要求修改密码。
2. 安装ifconfig工具，`sudo apt-get install net-tools`
3. 开启ssh
    - `sudo apt-get update`,
    - `sudo apt-get install openssh-server`
    - 无法启动查看错误 `sshd -T`
    - 重新生成密钥 `sudo ssh-keygen -A`
    - 重启系统
4. 配置wifi（可选）
    - `sudo vi /etc/netplan/50-cloud-init.yaml`
    ```sh
    network:
        ethernets:
            eth0:
                dhcp4: true
                optional: true
    version: 2
    wifis:
        wlan0:
            dhcp4: true
            access-points:
                "你的wifi的ssid":
                    password: "你的密码"
    ```
    - `sudo netplan try`
    - `sudo netplan apply`
