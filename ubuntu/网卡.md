# 网卡

## 18.04

1. 查看使用中的网卡，ifconfig。
2. 查看全部网卡，ifconfig -a。
3. 启用网卡 sudo ifconfig xxx(例如eth0) up/down。
4. 修改固定ip，sud xxxx，更新netplan apply。

``` shell
network:
  ethernets: 
    ens33: 
      dhcp4: no
      addresses: [192.168.217.10/24]
      gateway4: 192.168.217.2
```

## 16.04

## 无线

1. `sudo vi /etc/network/interfaces`,添加如下配置
    auto wlan0
    iface wlan0 inet static
    address 192.168.0.150
    netmask 255.255.255.0
    gateway 192.168.0.1
    dns-nameserver 192.168.0.1
    wpa-ssid xxxxxx
    wpa-psk yyyyyyy

## 有线

1. `sudo vi /etc/network/interfaces`,添加如下配置

    auto eth0
    iface eth0 inet static
    address 192.168.1.211
    netmask 255.255.255.0
    gateway 192.168.1.1
    dns-nameserver 192.168.0.1

## 修改dns

1. `vim /etc/resolv.conf`，添加`nameserver 114.114.114.114`

## 重启网路

1. `sudo service networking restart`

## 命令行修改网络

1. 查看里面的网络配置 `/etc/NetworkManager/system-connections/`
2. 查看网络 `nmcli con show`
3. 重启网络 `nmcli con down eth0`， `nmcli con up eth0`
