# 网卡

## 18.04

1. 查看使用中的网卡，ifconfig。
2. 查看全部网卡，ifconfig -a。
3. 启用网卡 sudo ifconfig xxx(例如eth0) up/down。
4. 修改固定ip，vi /etc/netplan/xxxx，更新netplan apply。

``` shell
network:
  ethernets: 
    ens33: 
      dhcp4: no
      addresses: [192.168.217.10/24]
      gateway4: 192.168.217.2
```

## 16.04

## 无线

1. `sudo vi /etc/network/interfaces`,添加如下配置
    auto wlan0
    iface wlan0 inet static
    address 192.168.0.150
    netmask 255.255.255.0
    gateway 192.168.0.1
    dns-nameserver 192.168.0.1
    wpa-ssid xxxxxx
    wpa-psk yyyyyyy

## 有线

1. `sudo vi /etc/network/interfaces`,添加如下配置

    auto eth0
    iface eth0 inet static
    address 192.168.1.211
    netmask 255.255.255.0
    gateway 192.168.1.1
    dns-nameserver 192.168.0.1

## 修改dns

1. `vim /etc/resolv.conf`，添加`nameserver 114.114.114.114`

## 重启网路

1. `sudo service networking restart`

## 命令行修改网络

1. 查看里面的网络配置 `/etc/NetworkManager/system-connections/`
2. 修改ip `sudo nmcli con mod 'Wired connection 1' ipv4.addresses 192.168.1.2/24 ipv4.gateway 192.168.1.1  ipv4.dns "8.8.8.8,114.114.114.114" ipv4.method manual`
3. 启动/关闭网络 ` sudo nmcli connection up 'Wired connection 1'` ` sudo nmcli connection down 'Wired connection 2'`
4. 查看状态 `nmcli device status` `nmcli connection` `nmcli con show`
