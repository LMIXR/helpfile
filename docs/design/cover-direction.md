# Signal Atlas

秩序来自可追踪的关系。细线、圆环与规则点阵构成一种测量语言，留白让各个形体拥有明确的边界。线条的粗细和间距需要经过仔细校准，让复杂结构在缩小后仍然清楚。

深海蓝承载安静的空间，略带暖意的白色形成阅读重心。青绿色只用于表达正在发生的连接，灰蓝色承担背景结构。色彩的价值来自严格控制的比例，以及对明暗层次的细致推敲。

尺度建立观看顺序。大字号提供第一眼的落点，小字号像仪器上的刻度，帮助观看者在靠近时发现细节。无衬线字体与等宽字体各有职责，精确的基线、字距与边距让整体保持稳定。

几何形体沿着一个明确方向展开，重复的节点形成节奏，折线连接建立连续性。每一次转折都需要有理由，每一个端点都应准确落位。细节体现耐心，而有限的元素使这些细节能够被看见。

完成度取决于删减和校准。检查小尺寸下的对比度、图形与文字之间的距离，以及四周留白是否均衡。最终画面应像经过反复整理的技术图版，清楚、克制，又保留值得停留观察的细部。
