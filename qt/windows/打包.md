# 打包

1. 把exe文件拷贝到新的文件夹内。
2. 新建环境变量"VCINSTALLDIR"=C:\Program Files (x86)\Microsoft Visual Studio 14.0\VC
3. cmd到新文件夹内，执行`windeployqt *.exe`，当前目录下自动导入依赖文件。
4. 把libmysql.dll拷贝到新文件夹。

# 查看依赖库

1. `C:\Program Files (x86)\Microsoft Visual Studio 14.0\VC\bin>dumpbin.exe /dependents *.exe`
2. 依赖文件目录`C:\Program Files (x86)\Microsoft Visual Studio 14.0\VC\redist\x64\Microsoft.VC140.CRT`
