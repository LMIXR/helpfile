# 可执行文件

## 修改可执行文件

1.  pro文件加入 `QMAKE_LFLAGS += -no-pie`，重新编译，双击可启动。
2. 把图标icon.png放在和可执行程序相同目录。
3. 新建 `touch app.desktop`，修改文件权限 `chmod a+x  app.desktop`，修改Name，Exec，Icon。
4. 信任app.desktop，`gio set app.desktop metadata::trusted yes`，查看信息 `gio info aiface.desktop`。
