# 打包

1. 新建文件pack.sh，修改里面到参数，执行`./pack.sh`，目录会导入相关库。
2. 如果使用mysql或者sqlite数据库，在文件夹内新建sqldrivers目录，放入libqsqlmysql.so，libqsqlite.so。
3. 如果是双击运行程序，需要在/usr/local/lib里查找动态连接库时，需要编辑`sudo vi /etc/ld.so.conf`，最后添加`include /usr/local/lib`，
    然后执行命令`sudo /sbin/ldconfig -v`, 或者（优先级高）添加 /etc/ld.so.conf.d/***.conf, 里面包含库路径，执行`sudo ldconfig`。
    或者在start.sh里加入export LD_LIBRARY_PATH=LD_LIBRARY_PATH:*****，但是这样sudo调试不能找到本目录的库。
4. 将程序放在某个目录，添加/etc/ld.so.conf.d/***.conf, 里面包程序路径，执行`sudo ldconfig`

## 16.04 自启动服务

1. 创建服务，修改server.sh文件内容，PROG为程序名字，PROG_PATH为程序路径。
2. 把server.sh放到/etc/init.d目录下。
3. 修改文件权限 chomd 777 /etc/init.d/server.sh
4. 添加服务`sudo update-rc.d 程序名字 defaults`，删除服务`sudo update-rc.d -f 程序名字 remove`
5. 启动服务`sudo /etc/init.d/程序名字 start`，停止服务`sudo /etc/init.d/程序名字 stop`

## 18.04 自启动服务

1. 创建启动文件，`sudo vi /opt/server/start.sh` 修改权限`sudo chmod a+x /opt/server/start.sh`。
2. 创建停止文件，`sudo vi /opt/server/stop.sh` 修改权限`sudo chmod a+x  /opt/server/stop.sh`。
3. 创建服务文件 `sudo vi /etc/systemd/system/server.service`, 修改权限`sudo chmod a+x /etc/systemd/system/server.service`。
4. 通知有新服务`sudo systemctl daemon-reload`。
5. 启动`sudo systemctl start server.service`，停止 `sudo systemctl stop server.service`，查看状态`sudo systemctl status server.service`，启用`sudo systemctl enable server.service`。
